System services (daemons)

  • Modes

    • super daemon — xinetd stays in memory and manages others via /etc/xinetd.d/* (telnet)

Process management

&

  • Run in the background

ctrl+z

  • Stop the process and push it to the background

bg

  • Resume stopped background jobs

fg

Job scheduling

at

  • start service: /etc/init.d/atd restart; chkconfig atd on
  • -m # email when job completes
  • -l # same as atq; list this user’s jobs
  • -d num # same as atrm; cancel job

  • -c num # show job contents

batch

Linux disk quotas — fstab, quotacheck, edquota, journaled quota

鸟哥的Linux私房菜-配额

Notes from Bird’s Linux Private Kitchen (3rd edition), kept for quick review.

Disk quotas

One-shot enable:
mount -o remount,usrquota,grpquota # matches /etc/mtab

Persist across boots — edit /etc/fstab
UUID=XXX ext4 defaults,usrquota,grpquota 0 0
umount
mount -a
mount | grep # confirm quota options

quota

  • -auvg — scan filesystems that need quotas [a: from /etc/mtab; u: user; g: group]
  • -mf — force check and write quota files

笔记记录于《鸟哥的Linux私房菜-第三版》,以备多看。

配额

单次生效：
mount -o remount,usrquota,grpquota 单独的filesystem #对应/etc/mtab

每次开机有效 编辑/etc/fstab
UUID=XXX 单独的filesystem ext4 defaults,usrquota,grpquota 0 0
umount 单独的filesystem
mount -a
mount|grep 单独的filesystem #确认是否添加quota

quota

  • -auvg #扫描需要quota的filesystem [a-/etc/mtab中找需要quota的filesystem;u-user;g-group]
  • -mf #强制执行检查写入
