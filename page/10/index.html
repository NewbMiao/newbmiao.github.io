Faster responses with fastcgi_finish_request (PHP-FPM)

利用fastcgi_finish_request加快页面响应

fastcgi_finish_request() flushes all response data to the client and ends the request. The worker can keep running heavy work after the connection closes.

With PHP-FPM this is a simple “respond first, finish later” pattern. Notes mostly followed Huoding’s post (2011, concept still applies).

fastcgi_finish_request

此函数冲刷(flush)所有响应的数据给客户端并结束请求。 这使得客户端结束连接后，需要大量时间运行的任务能够继续运行。
