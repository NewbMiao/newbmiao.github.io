mb_strlen “broken” on the server

Locally mb_strlen('哈') was 1; on the server it was 3 — almost always charset config.

mb_strlen defaults to mb_internal_encoding(). The old mbstring.internal_encoding ini directive was deprecated in PHP 5.6; use default_charset instead.

On the server default_charset was unset, so PHP fell back to ISO-8859-1.

File-based session locking

Under concurrency, file-backed sessions are painful because PHP sessions use a read/write lock on the session file.
