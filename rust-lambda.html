AWS Lambda is a lightweight compute service: pay for what you use and let AWS handle packaging and scaling.

Billing tracks duration and memory, which is where Rust tends to shine—hence all the serverless handlers written in Rust.

Below: cargo-lambda for a Rust handler, local watch, and a LocalStack deploy—you don’t need a real AWS account for the sandbox at the end.
