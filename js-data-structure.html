JavaScript data types — cheat sheet

Types

String vs String object

  • Primitives coerce to object wrappers when needed.
  • Strings are immutable; methods return new values.

Number

  • IEEE double arithmetic: 0.1 + 0.2 !== 0.3
  • Use Number.isNaN / isFinite (prefer over legacy globals)

null / undefined

  • null — intentional absence of object reference
  • undefined — uninitialized binding

Boolean

  • new Boolean(false) is truthy as an object; Boolean(false) is false

Array

  • Assignment copies reference; clone shallowly with concat or spread
  • delete leaves holes; prefer splice to remove elements

Statements

  • switch uses strict ===
  • try/catch/finally — only one catch arm (pre-ES2019); use finally for cleanup

Variables and objects

  • Assignment copies object references
  • Parameters are passed by value of the reference — swapping primitives inside a function does not swap outer variables unless you return new values:
  • Properties on the prototype chain may not delete from the instance (delete obj.x can fail silently for inherited props)

Immutability helpers

  • Object.preventExtensions — no new properties
  • Object.seal — no add/delete
  • Object.freeze — no add/delete/change

JSON

Avoid eval for JSON. Today also consider structuredClone for deep copies of plain data when appropriate.
